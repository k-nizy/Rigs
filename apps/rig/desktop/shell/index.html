This shell has no floor address

RIG_URL is not set, is empty, or is not a URL, so there is nothing to open. No rig page is bundled in this binary, deliberately — the page has to come from the floor, because that is how a machine learns which rig it is. 

RIG_URL=http://floor.internal/apps/rig/

That address is the same on every machine on the floor. It is not this rig’s identity: the service works out which rig is calling from the address the request arrives on, and a machine it cannot place is told it is nobody rather than guessed at.

This rig cannot write down what it records

The shell could not open its journal, so nothing recorded here would survive a power cut — or a reload. 


  

    It is deliberately not opening the floor’s rig page. A page with
    no journal quietly falls back to the browser’s own, and that one also
    reports itself durable, so an operator would be told their work was safe
    by the one machine that had just failed to make it so.
  

  

    RIG_JOURNAL_DIR says where the journal lives; without it the
    shell uses /var/lib/rig. Whatever starts this shell has to
    create that directory and let this user write to it.
  

  

    Idle time is loud, cheap and recoverable. Work filed by a rig that could
    not write it down is none of those, which is why this screen is here
    instead of a working-looking pedal.
